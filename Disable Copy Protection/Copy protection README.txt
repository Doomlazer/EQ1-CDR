As I mentioned in the link above, I restored the copy protection in this release for two reasons.

1. It's the least annoying copy protection possible; just a static four digit code, 9731
2. When I first tried reactivating the keypad, I discovered that it crashed in the CD version. I personally believe it was removed because Ken didn't want to spent money fixing bugs. Though, it might have been because they felt CD games couldn't be pirated at the time. I fixed the keypad crash as a personal challenge. Plus, it makes sense in-game to have a lock on your Livingroom's dolphin door.

Since Froakienin2022 asked, I've added this patch to optionally remove the keypad again. Just drop 400.scr into the patch folder, replacing the existing version.
